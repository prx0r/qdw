# Review Infrastructure as a QDW Capability

Once integrated, this is useful beyond QDW itself.

Every factory-produced repo can inherit:

```text
review architecture
review API
review app
review connector
review package
review agent
review commerce
review data-pipeline
```

The same contractor layer can become part of public products later:

- automated repository architecture audit;
- API red-team review;
- agent/MCP trust-boundary audit;
- migration/provenance audit;
- release readiness certificate;
- agent-generated-code fake-green detector.

Internally, QDW should dogfood it first.
